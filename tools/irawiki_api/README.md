# irawiki_api — salinan baca-saja (server-only)

Sumber asli (tempat yang benar-benar dijalankan):

    /home/ubuntu/irawiki_api/     <- uvicorn main:app :8000
    /home/ubuntu/.hermes/skills/irawiki/SKILL.md

Folder ini adalah salinan untuk version control saja, karena `irawiki_api/`
tidak berada di dalam repo git mana pun. **Setelah mengubah file di
`/home/ubuntu/irawiki_api/`, salin ulang ke sini dan commit.**

Tidak ada `.env` (berisi IRAWIKI_MUSE_API_KEY) di folder ini — sengaja.
